# Safety App Backend API

FastAPI backend for Safety App MVP with YOLO v11 PPE violation detection.

## Features
- Real-time PPE violation detection using YOLO v11
- Dual camera modes (Prevention & Incident Reporting)
- User authentication with auto-login
- Firebase integration for data storage
- Real-time dashboard analytics
- Live streaming support
- Push notifications
